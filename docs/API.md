# Mewmer API Usage

Base URLs:

- Local development: `http://localhost:3030/api/v1`
- Production: `https://api.mewmer.com/api/v1` (replace `api.mewmer.com` with your real domain)

See `docs/PRODUCTION.md` for full backend deployment steps.

All authenticated endpoints accept the session via either:
- An HTTP-only cookie named `session` (set automatically on login), or
- An `Authorization: Bearer <token>` header.

## Admin user creation

The first admin account must be created with the CLI tool. The password is supplied as a one-off environment variable; the CLI hashes it with Argon2id and stores only the hash in PostgreSQL.

```bash
cd server
export ADMIN_EMAIL=you@mewmer.com
export ADMIN_USERNAME=yourusername
export ADMIN_DISPLAY_NAME="Your Name"
export ADMIN_PASSWORD="a strong password"
go run ./cmd/create-admin
```

If the email already exists, the tool updates the password and forces the role to `admin`. Do **not** put `ADMIN_PASSWORD` in `server/.env`; pass it only for the command.

## Authentication

### Login

```bash
curl -X POST http://localhost:3030/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"you@mewmer.com","password":"your password"}'
```

Response:
```json
{
  "user": { "id": "...", "email": "...", "username": "...", "displayName": "...", "role": "admin" },
  "token": "<bearer-token>"
}
```

Use the bearer token for Flutter or scripts. The web frontend can rely on the `session` cookie instead.

### Get current user

```bash
curl http://localhost:3030/api/v1/auth/me \
  -H "Authorization: Bearer <token>"
```

### Logout

```bash
curl -X POST http://localhost:3030/api/v1/auth/logout \
  -H "Authorization: Bearer <token>"
```

## Meme templates

Templates are public to read and admin-only to upload.

### Upload a template (admin only)

```bash
curl -X POST http://localhost:3030/api/v1/templates \
  -H "Authorization: Bearer <token>" \
  -F "title=Distracted Boyfriend" \
  -F "slug=distracted-boyfriend" \
  -F "tags=funny,relationship,choice" \
  -F "description=Classic choice meme" \
  -F "media=@template.png"
```

Supported formats: JPEG, PNG, GIF, WebP. At least 3 comma-separated tags are required.

### List public templates

```bash
curl "http://localhost:3030/api/v1/templates?q=boyfriend&tag=funny&sort=popular&page=1"
```

`sort` can be `newest` (default) or `popular`.

### Get a single template

```bash
curl http://localhost:3030/api/v1/templates/distracted-boyfriend
```

## Sticker packs and stickers

Packs and stickers are owned by the authenticated user. Media is stored in the private R2 bucket and returned as short-lived signed URLs (in local filesystem mode it returns a local `/uploads/...` URL).

### List my packs

```bash
curl "http://localhost:3030/api/v1/me/packs?q=my+pack&page=1&limit=10" \
  -H "Authorization: Bearer <token>"
```

- `q` — optional search across title and tags (case-insensitive).
- `page` — defaults to `1`.
- `limit` — defaults to `10`, maximum `50`.

Response:
```json
{
  "packs": [...],
  "page": 1,
  "limit": 10,
  "total": 42
}
```

### Create a pack

```bash
curl -X POST http://localhost:3030/api/v1/packs \
  -H "Authorization: Bearer <token>" \
  -F "title=My Pack" \
  -F "visibility=private" \
  -F "tags=meme,funny,reactions" \
  -F "tray=@tray-96x96.png"
```

- `visibility` is optional and defaults to `private` (`private`, `unlisted`, `public`).
- `isAnimated` is optional (`true` or `false`, defaults to `false`).
- `tags` is optional; supply comma-separated values.
- The tray icon must be a 96×96 PNG or WebP under 50 KB.

### Get a pack with stickers

```bash
curl http://localhost:3030/api/v1/packs/<pack-id> \
  -H "Authorization: Bearer <token>"
```

### Add a sticker to a pack

```bash
curl -X POST http://localhost:3030/api/v1/packs/<pack-id>/stickers \
  -H "Authorization: Bearer <token>" \
  -F "sticker=@sticker-512x512.webp" \
  -F "isAnimated=false" \
  -F "emojis=😂,👍"
```

- Static stickers must be 512×512 WebP under 100 KB.
- Animated stickers must be 512×512 animated WebP under 500 KB.
- A pack cannot mix static and animated stickers.

### Delete a sticker

```bash
curl -X DELETE http://localhost:3030/api/v1/stickers/<sticker-id> \
  -H "Authorization: Bearer <token>"
```

### Delete a pack

```bash
curl -X DELETE http://localhost:3030/api/v1/packs/<pack-id> \
  -H "Authorization: Bearer <token>"
```

Deleting a pack also deletes its sticker rows (database cascade) and the associated media files.

## Media storage

- **Public bucket** (`mewmer-public-media`): template images and future public memes.
- **Private bucket** (`mewmer-private-media`): sticker packs, tray icons, and stickers.

In production (`STORAGE_TYPE=r2`), public media is served through the custom domain configured in Cloudflare R2, and private media is served through presigned URLs generated by the Go backend. In local development (`STORAGE_TYPE=filesystem`, the default), media is written under `server/uploads/<bucket>/` and served through the existing `/uploads/*` static route.
